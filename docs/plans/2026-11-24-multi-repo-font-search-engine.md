# Unified Multi-Repository Free Font Search Engine — Approved Plan

> **Execution Mode:** Subagent-Driven (`plan-driven-development`).
> **User Policy Confirmed (2026-11-24):** Maximize font access — keep direct 1-click desktop download wherever an upstream binary endpoint works (including Fontshare's official API, Google Fonts full desktop binaries, Homebrew Open, Scoop, League of Moveable Type, Open Font Repository, Fontsource, Bunny, Nerd Fonts, GitHub releases), display clear license badges + origin links on every font so the user can verify compliance, and use `origin_link` (`Open Source Page ↗`) for WAF-gated or directory-only providers (Font Squirrel 608 via FontGet-Sources, Fontesk live WP REST 13k+, Tier 3–6 Mega Directories).

## Core Architecture Guardrails
1. **Full Unmodified Desktop Binaries First:** Keep lightweight WOFF2 previews on Fontsource/Bunny CDN, but route Google-backed installs (`google`, `bunny`, Google-sourced `fontsource`) to `fonts.google.com/download/list` first so desktop installs get full unmodified `.ttf`/`.otf` fonts rather than Latin-only web subsets.
2. **Clear Licensing & Origin Links:** Every entry carries `description`, `homepage`, `license`, `tags`, `sha256`, `redistribution_allowed`, and `download_mode` (`"direct"` vs `"origin_link"`). Fontshare stays `"direct"` with `license: "ITF-FFL (Free Personal & Commercial)"` + `homepage` link. Font Squirrel (`font-squirrel.json`, 608 fonts) and Fontesk live WP REST (`13,000+` fonts) use `"origin_link"` since their download endpoints are WAF-gated / directory-only.
3. **7-Day Local Cache + SSRF & SHA-256 Hardening:** Structured JSON registries sync into local 7-day caches (`homebrew-fonts-slim.json`, `scoop-fonts-index.json`, `fontget-fontsquirrel.json`, `fontget-league.json`, `open-font-repository.json`, `gwfh-fallback.json`). Multi-host downloads enforce HTTPS-only, `custom_http_client()` SSRF guard, optional SHA-256 verification, and `.ttf`/`.otf`-only extraction.

# Changelog

All notable changes to **Cosmic Font Foundry** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] - 2026-11-18

### Added
- **Tranquil Nebula UI Overhaul:** Warm obsidian, crimson-coral, solar orange, and golden amber color scheme (`Dark` & `Light` themes), matching app icon, semantic Lucide sidebar icons, frosted-glass header, and elevated card/row interactions.
- **Multi-Foundry Discover & Custom Feed Subscriptions:** Browse Google Fonts, Fontshare, Fontsource Open Foundry, Adobe & Dev originals, and Font Squirrel; subscribe to custom RSS 2.0, Atom XML, JSON Catalogs, GitHub Releases, and one-click community presets with `New Release` / `Update Available` badges.
- **Forge Studio:** Modular `7×9` and `14×18` grid font creator with parametric DNA sliders, accented Latin glyphs (`Á, É, Í, Ó, Ú, Ñ, Ü`), live `.ttf` SFNT binary compilation, export, and one-click Windows installation.
- **Smart PC Font Scanner & OS Auto-Collections:** Detect Windows default font folders, scan Downloads/Desktop/Documents/Adobe directories, and algorithmically organize OS font collections with zero ML dependencies.
- **Formatting Sampler & Token Export:** Live `B / I / U / S / AA` formatting controls, 8-card Standard Formatting Matrix in Specimen, and one-click CSS & Tailwind design token export from Collections and Compare pairings.
- **Hidden Agent Hub & Loopback MCP Server:** Localhost-only (`127.0.0.1:17420`) MCP JSON-RPC 2.0 & REST control plane, read-only vs. write-control gating, deterministic 0 MB command director, and optional BYO-AI (Ollama / OpenAI-compatible) integration, tucked inside Settings.
- **FOSS Governance & Quality Tooling:** `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `GOVERNANCE.md`, `MAINTAINERS.md`, `REUSE.toml`, `.pre-commit-config.yaml`, and CI lint/secret/license checks.
